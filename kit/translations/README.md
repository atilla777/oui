# Переводы по явному ключу

Самостоятельный пакет Odin без Slyx, UI, SDL и внешних словарей. Рабочий потребитель со своим словарём: [consumer/translations](https://github.com/atilla777/slyx/blob/8c55d0da6a28fe7d15f58f828b10a25a2851fea7/examples/translations/main.odin). Из корня этой копии:

```sh
odin test kit/translations
odin check kit/translations -no-entry-point -vet -vet-style -vet-tabs -vet-semicolon
odin run consumer/translations
```

## API и данные

- `Entry {key: string, texts: []string}`: ячейки следуют порядку языков.
- `init(languages: []string, entries: []Entry) -> Init_Result`: вариант `Catalog` **или** `Init_Error {kind, key, language}`. Виды: `Empty_Language`, `Duplicate_Language`, `Empty_Key`, `Duplicate_Key`, `Invalid_Translation_Count`. Диагностические key/language заполнены там, где применимы. Ошибка не содержит пригодного каталога. Пустые списки допустимы; пустые ячейки разрешены для отдельной диагностики полноты.
- `lookup(catalog, key, language) -> Lookup_Result`: вариант `string` **или** `Lookup_Error`. Приоритет: `Unsupported_Language`, затем `Unknown_Key`, затем `Missing_Translation`. У ошибки нет строкового результата, запасного языка или подстановки ключа.
- `validate_complete(catalog) -> Validation_Result`: `Complete {}` **или** `Completeness_Error {key, language}` для первой пустой ячейки в порядке записей, затем языков. Приложение должно отклонить неполный каталог до создания отображаемого текста.

Ключи/языки сравниваются точно, без смены регистра и Unicode-нормализации. Пустым переводом считается строка длины ноль; пробелы и Unicode возвращаются без преобразований. Обычный и краткий тексты — самостоятельные ключи, `.short` не имеет специального значения. Линейный поиск не выделяет память и не копирует строки. Нет текущей локали, `max_chars`, обрезки, выбора формы, форматирования или подсчёта графем. Лимиты графем проверяет потребитель; пиксельные размеры и переполнение — UI.

## Владение

Создавайте `Catalog` только через успешный `init`; `lookup` и `validate_complete` требуют такого каталога. Не конструируйте и не меняйте его поля вручную. Каталог заимствует **все** исходные массивы (включая `Entry.texts`), ключи и строки. Они должны оставаться живыми и неизменными до окончания использования каталога **и всех возвращённых строк**. Срез не продлевает жизнь данных; очищаемый временный аллокатор не подходит для долгоживущего каталога. `destroy` нет: библиотека ничего не освобождает. Чтение неизменного словаря допускается параллельно.

Пример держит локальные массивы живыми до конца использования. Slyx держит массивы в статическом хранилище и заимствует встроенные `#load` строки до завершения процесса; удаление краевых пробелов выполняет адаптер игры, не библиотека. Изменение поставляемого текста требует пересборки.
