# Правила сопровождения oui

- [Разработка и MIS](development.md) — источники истины, границы изменений,
  worktree, ревью и публикация.
- [Проверки](checks.md) — согласованный минимум, адресные тесты, полная приёмка
  и изоляция ресурсов.

Эти правила относятся к сопровождению репозитория, не добавляют обязательных
инструментов обычным потребителям kit. Контракты библиотеки начинаются
с [docs/README.md](../README.md), краткое назначение — в [product](../product/index.md).
