# Знакомство с oui

oui — экспериментальный набор пакетов Odin для интерфейсов небольших игр. Это не игра, не движок и не универсальный UI-фреймворк. Приложение выбирает необходимые части, а не получает обязательный каркас.

## Что предоставляет набор {#what-it-provides}

Набор отделяет headless layout от interaction и text, необязательных семейств компонентов и backend SDL3. Примеры показывают интеграцию, но не являются обязательной основой приложения.

## Перед началом {#before-you-start}

API экспериментальный: совместимость со старым umbrella `ui` и произвольная композиция всех семейств не обещаны. Модель и значимые значения принадлежат приложению. Лицензии ресурсов и сторонние notices сохраняют силу.

Продолжите с раздела [использование oui](./guide/using-oui). Авторитетные технические контракты находятся в [документации репозитория](https://github.com/atilla777/oui/tree/main/docs).
