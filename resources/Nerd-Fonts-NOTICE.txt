Modifications by the Slyx project: character subsetting and renaming the
font family/PostScript name to Slyx UI / SlyxUI-Regular. Copyright/license
metadata is retained. Other Nerd Fonts icon sets are not shipped.

Slyx Rich Fallback / SlyxRichFallback-Regular is a second subset of the same
pinned source, containing only space, combining acute, alpha, Omega, Greek alpha
with tonos and infinity. Its original copyright/license metadata is retained;
it does not include private-use icons or alter the primary Slyx UI subset.

When distributing the game (including a binary with the embedded font),
include DejaVu-LICENSE.txt, Octicons-LICENSE.txt and this notice.
