# Provenance and source ownership

oui is the maintained portable root: kit/, consumer/, resources/, tests/, scripts/,
docs/, skills/ and preparation/. See [the source map](../inventory.json) and
[extraction boundary](extraction.md). Consumers need no Slyx checkout or workflow.
The historical Slyx exporter was a bounded distribution proof, not this full
extraction. It is not an acquisition prerequisite. Export/proof copies are
disposable read-only inputs, never a second maintained source.

The standalone history begins from a new root, without imported Slyx objects.
Original attribution/header notices are preserved. Git author identity does not
assert human content acceptance. MIT covers only selected original material;
third-party notices remain separate. Published acquisition and v0.1.0 release
are pending exact-revision independent checks, not claimed by local bootstrap.
