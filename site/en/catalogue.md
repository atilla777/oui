# Capability catalogue {#catalogue}

This is an explicitly limited sample, not the complete showcase catalogue. It
currently covers three of the 19 gallery sections and none of the four Integration
Lab screens. The captures show the native application, not a browser port.

## Layout {#layout}

Arrange geometry using rows, columns, stacks, grids, absolute placement and
clipping. [Explore layout and its native example](./capabilities/layout).

## Scroll and table {#scroll-table}

Scroll an ordinary table through a vertical viewport. [Explore the native example](./capabilities/scroll-table).

## Virtual collections {#collections}

Materialize the visible portion of a uniform list or grid. [Explore the native example](./capabilities/collections).
