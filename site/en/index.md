# Introducing oui

oui is an experimental collection of Odin packages for user interfaces in small games. It is not a game, an engine, or a universal UI framework. Applications choose the pieces they need instead of adopting a complete application shell.

## What the kit provides {#what-it-provides}

The kit separates headless layout from interaction and text, optional component families, and an SDL3 backend. Examples demonstrate integration; they are not mandatory scaffolding for consumers.

## Before you start {#before-you-start}

The API is experimental and does not promise compatibility with the old umbrella `ui` or arbitrary composition of all families. Your application owns its model and meaningful values. Resource licenses and third-party notices remain applicable.

Continue with [using oui](./guide/using-oui). For the authoritative technical documentation, see the [repository documentation](https://github.com/atilla777/oui/tree/main/docs).
